CARA MENJALANKAN
1. Download ZIP.
2. Ekstrak ZIP.
3. Buka folder.
4. Klik index.html.
5. Game langsung dimainkan (tanpa internet, tanpa instalasi).

MENYIMPAN PROGRES
Progres tersimpan otomatis di browser pada perangkat yang sama (localStorage).
Gunakan browser dan perangkat yang sama agar progres tidak hilang.
Jangan mengosongkan data situs browser jika ingin mempertahankan progres.

MENGHAPUS PROGRES
Buka Menu > tombol "RESET PROGRES" > konfirmasi.
